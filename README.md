\# ECHO07\_PA2



Vertical Slice 2D desarrollado en Unity.



\## Sistemas implementados

\- Tilemap sci-fi

\- Cinemachine 2D

\- Animator con Idle, Run y Jump

\- HUD responsivo

\- Audio y partículas

\- Energy Cores

\- Power Batteries

\- Exit Zone

\- Patrón Singleton / Observer



\## Aporte

Se realizó revisión del proyecto, validación del flujo jugable y documentación del repositorio.
